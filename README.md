# House-price-prediction
House Price Prediction (Machine Learning)
Overview

This project implements a machine learning system to predict house prices based on key property features. It demonstrates a complete regression-based workflow, including data preprocessing, model training, evaluation, and prediction.

Tech Stack

Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

Dataset

Real estate housing dataset containing features such as area, location, number of bedrooms, and bathrooms.
Target variable: House Price

Models Used

Linear Regression

Ridge and Lasso Regression

Decision Tree Regressor

Random Forest Regressor

Evaluation Metrics

R² Score, Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE)

How to Run
pip install -r requirements.txt
jupyter notebook
